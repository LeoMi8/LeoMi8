## Featured Projects

### GalaxyTrucker
**Java · Maven · MVC · Socket Programming**

A multiplayer digital adaptation of the Galaxy Trucker board game, developed as a university software engineering project.

- Object-oriented design following the MVC architectural pattern.
- Socket-based client-server communication.
- Multiple concurrent game sessions and data persistence.
- 78% line coverage of the Model.

[Explore Repository](https://github.com/LeoMi8/GalaxyTrucker)

### VHDL Priority-Based Task Manager
**VHDL · Xilinx Vivado · Digital Logic Design**

An FSM-controlled hardware module designed to manage a priority-ordered task queue in external synchronous RAM.

- Four operations for task insertion, extraction, priority updates, and queue clearing.
- Dedicated control unit and register-based datapath.
- Behavioral simulation and post-synthesis analysis.

*University project — currently private.*

### SAT Solver
**C · Boolean Satisfiability · Algorithms**

A Boolean satisfiability solver developed in C to evaluate hierarchical preference constraints.

- Recursive backtracking.
- Unit propagation and contradiction detection.
- Dynamic memory management and Boolean formula evaluation.

*University project — currently private.*
